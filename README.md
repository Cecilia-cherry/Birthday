# 欢迎进入我们的世界

给 8 月 12 日的一份生日礼物。五座城市、一个宇宙。

首屏采用居中的 3D 星空序章，保留原版紫白色衬线字。时空记忆逐字浮现、整段淡出，再显示进入邀请；约 6.25 秒后解锁选择。星球采用柔和云纹和光晕，鼠标移动会产生星光拖尾和景深视差。点击“进入我们的世界”进入蛋糕场景；“暂时不要”进入等待画面，可继续进入或返回选择。按钮保持固定位置。点击“跳过序章”或按空格直接显示选择；左右方向键切换选项，回车确认。重播从序章重新开始，减少动画模式直接显示选择。

## 本地打开

需要 Node.js 20 或更新版本。网站运行无需安装第三方依赖：

```sh
npm run dev
```

浏览器打开 http://localhost:5173 。请通过本地服务打开项目中的 `index.html`；导出的独立网页可以直接双击打开。

也可以直接用浏览器打开项目中的 **欢迎进入我们的世界.html**，这份独立网页已打包好，仍可填写回忆并再次导出。修改源码后，运行 `npm run gift` 可重新生成它。

## 填入你们的回忆

点击右上角的铅笔，选择城市，填写旅行时间、星球名称、标题和回忆文字。选择照片后，点击其中一张设为封面，再点击“保存这段回忆”。

- 厦门已填入：2022 年 11 月、鼓浪屿星球、第一次一起看海。
- 上海、嘉兴、中山、珠海的时间和回忆等待填写，没有代编旅行经历。
- 每座城市最多 10 张照片，厦门建议 5–10 张。支持 JPG、PNG、WebP、AVIF；HEIC 请先转为 JPG。
- 照片在浏览器里处理，长边最多 1800 像素，压缩为 WebP，保留完整画面。打开相册会预载当前照片和相邻照片。
- 默认无背景音乐。若要添加，可将音频放在 `public` 下，并在 `public/memories.json` 的 `music` 字段填写 `./public/music.mp3`。音乐只会在点击进入后尝试播放，可随时关闭。

## 发给他

编辑页的“导出礼物网页”会下载 **欢迎进入我们的世界.html**，把当前保存的照片、文字、样式和动画一起放进单个文件，无需网络即可在浏览器打开；若配置音乐，也会一起打包。可以再编辑并重新导出。

编辑记录只保存在当前浏览器的 IndexedDB，清理浏览器数据会丢失本地草稿。**分享时请发送导出的网页文件，而非本地预览地址。** 请保留导出的副本。

如果希望在手机上通过链接访问，可将导出的 HTML 重命名为 `index.html`，上传到支持静态网页的托管服务。手机文件预览器或部分聊天软件可能不运行网页脚本，通过浏览器访问托管链接体验更稳定。本项目没有自动发布到公网。

## 部署源码

```sh
npm run build
npm run preview
```

`dist/` 可以部署到静态网站托管服务。注意：构建只复制项目文件，不读取浏览器草稿。要发布在编辑页里保存的内容，请使用“导出礼物网页”；也可以直接编辑 `public/memories.json`，将照片放在 `public/photos/` 并在对应城市的 `photos` 数组中填写路径，如 `./public/photos/xiamen-01.webp`。`cover` 从 0 开始计数。

## 验证

```sh
npm install
npm test
```

浏览器测试使用已安装的 Google Chrome，需先启动 `npm run dev`。覆盖蛋糕粒子到生日信的完整流程、照片压缩和封面持久化、离线导出和再次导出、手机触摸、照片滑动及小屏布局。截图位于 `tests/artifacts/`。

视觉由本地 Canvas、CSS 和 SVG 绘制，字体随网页打包，运行时没有外部字体或图库请求，也没有分析追踪。支持键盘操作、Esc 关闭回忆、照片方向键切换、系统减少动画偏好；页面转入后台时暂停绘制。
